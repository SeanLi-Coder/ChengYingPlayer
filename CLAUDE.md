# Shared project instructions

Read `AGENTS.md` and `docs/AI_COLLABORATION.md` before working in this repository.
They are the shared instructions and handoff for all coding agents, including
Qwen when used through a client that loads this file. Do not maintain a divergent
copy of those rules here. Historical GLM work remains attributed to GLM.

For downloader work, also read `Tools/DownloaderHelper/UPSTREAM.md`. Check the
current branch and working tree, preserve other contributors' changes, and follow
the user's current task rather than resuming a cancelled standalone test kit.
