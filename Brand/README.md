# ChengYing brand assets

`ChengYingIconMaster.png` is the source image for the macOS application icon.
The files in `iina/Assets.xcassets/AppIcon.appiconset` are deterministic resized
copies generated from this master.

The master was generated with the built-in OpenAI image generation tool on
2026-09-16. The production prompt requested a text-free macOS icon combining an
abstract cinematic frame, a precise cut motif, and a play symbol, using a navy,
cyan, violet, and silver palette. It explicitly excluded third-party branding,
the upstream cone mark, text, and watermarks.
