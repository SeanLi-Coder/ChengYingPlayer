M4 AV1 独立硬解验收

要求：Apple Silicon arm64，macOS 26.0 或更新版本。本包不能用于旧版 macOS。
不需要项目源码、Python、Xcode 或 Homebrew；使用 macOS 自带 Perl 核心模块。

将整个 M4-AV1-Acceptance 文件夹复制到 M4 Max 上，保持内部文件不变。
双击 Run-M4-AV1-Check.command，或在终端执行：
  /bin/sh /完整路径/M4-AV1-Acceptance/Run-M4-AV1-Check.command
仅检查文件完整性，不运行解码：在命令末尾加 --verify-only。
路径中有空格时请加双引号，或把 command 文件拖进终端补全路径。

不会安装软件、打开播放器、联网、修改权限、上传结果或读取你的媒体。
只解码附带的 8-bit/10-bit 合成 AV1，核对真实帧、音频、seek、restart 和 reopen。
子进程只使用本包五个锁定的播放库，文件运行前后都核验 SHA-256。
原有 ad-hoc 链接签名保持不变；这不是 Developer ID 签名或 Apple 公证的安装包。
SHA 和 manifest 只检测意外损坏，不能认证发行者，也不抵御脚本与 manifest 被一同恶意改写。
如 macOS 阻止运行，请记录提示；本包不会自动解除隔离或修改系统安全设置。

结果位于本包 reports/run-*/report.json，可把这一份 JSON 发回开发者。
报告仅含相关 OS/架构、解码计数、退出状态、完整性及下述只读启动诊断，不含账号、序列号、
文件路径、网络信息或原始日志。没有自动上传。每次保留独立报告。
PASS 必须无软件回退、两种位深全部真实帧走硬件 VT，完整 1738 项检查无失败，
且实际加载库、运行前后文件身份都正确。M2 软件回退必须 FAIL，不是 M4 验收通过。
VERIFIED_NOT_RUN 只表示文件校验通过，完全不代表硬解通过。
FAIL 也可能表示硬件/OS 不支持、文件损坏、缺文件、超时或运行失败。
程序被系统信号终止时退出码为空，并明确报告信号；没有解码计数不代表机器不支持硬解。

启动前只读检查包内程序和五个库的签名完整性及隔离属性是否存在，每个命令最多 2 秒。
无法检查时标记 unavailable，不会当作通过或没有隔离。报告另含输出字节数、dyld 行数和摘要数量，
不保存原始输出。签名完整性通过不代表 Apple 公证或系统允许执行；不会自动解除隔离或重新签名。
--verify-only 也收集这些诊断，但 VERIFIED_NOT_RUN 不代表签名受信任、程序可启动或硬解通过。

范围仅为小型合成 AV1 解码；不代表完整 App、4K 长时播放、性能、HDR 屏幕或真实声卡验收。
本包是受控测试，不是通用下载器或播放器，也不代表默认播放后端已经切换。
