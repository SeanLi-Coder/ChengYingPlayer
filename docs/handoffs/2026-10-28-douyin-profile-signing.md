# 抖音整主页下载与签名页面重试

## 范围与实现

基于 `b6f94e31`，分支 `codex/douyin-profile-signing`；本轮由 Codex 负责发布。
用户授权使用本机 Chrome Profile 1 测试指定的两个主页，并要求保留完整下载。
随后明确改为桌面作者文件夹，便于硬盘拷贝，不再打压缩包。本次交付媒体是测试清理
约定的明确例外；Cookie、任务私有状态、签名媒体地址和原始网页不能进入交付目录
或仓库。暂停的播放内核实验不在本轮范围。

确认了可独立复现的重试缺陷：可信 HTML 缺少 SDK glue 时，首次请求收到的 Cookie
更新没有送入同一浏览器上下文，后续请求可能重复使用旧会话。现在仅同步本次响应中
发生变化的 name/domain/path 项，再执行原有浏览器请求；未变化的旧值不覆盖浏览器新值。
保留 host-only、Domain、path、Secure、HttpOnly 和到期语义，不写回 Chrome。

独立复审又补齐两个边界：同步失败立即丢弃当前上下文，由原有有界流程重建，最多三次；
自然过期或 urllib 清理过期记录不会误删浏览器刚续期的 Cookie，包括全部旧记录到期的情况。
明确全部撤销、登录／验证码、身份错误、网络过滤和取消仍停止相应流程。
最高画质、default 探测、作品归属、尺寸、时长、URL、TLS 和队列门禁保持不变。
